# Ecommerce
 Ecommerce belanja online yang modern dengan metode pembayaran yang lengkap dan mudah serta cepat.

## Fitur
- Crud Order
- Integrasi midtrans
- Sistem login
- Sistem transaksi

## Teknologi yang digunakan
- Bahasa pemrograman: Golang
- Framework: Gofiber
- Database: MariaDB
- Payment gateway: Midtrans

## Instalasi
1. Clone repository:

    ```bash
    https://github.com/nurmanhadi/ecommerce.git
    cd project
    go mod tidy
    ```
2. Setup environment:

    Sesuaikan file config.yaml ada ada di directory config/config.yaml

3. Jalankan Project
    ```bash
    go run cmd/main.go
    ```

## Dokumentasi API

Dokumentasi API tersedia dalam format Postman Collection. Anda dapat mengunduhnya dan mengimpornya ke Postman.
[Download API Documentation](./doc/ecommerce.postman_collection.json)
